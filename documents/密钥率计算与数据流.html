结论先行

一条密钥率曲线的计算链只有四步：

题目参数 p
\(\Downarrow\)
第 1 步：物理层 gain.m 把物理参数变成可观测量 \(Q,E,T\)
\(\Downarrow\)
第 2 步：统计层 fluct.m 给可观测量配上统计置信区间
\(\Downarrow\)
第 3 步：估计层 estimate.m 反推单光子参数的安全界 \(Y_1^{Z,L},e_1^{X,U}\)
\(\Downarrow\)
第 4 步：密钥率层 keyRateAt.m 拼成安全密钥率 \(R\)

runCase.m 只是把上面四步按距离逐点调用，并整理成数组： \[R(L)=\bigl[\;R(L_1),\;R(L_2),\;\ldots,\;R(L_{301})\;\bigr].\]

第 2 层：物理层 gain.m

gain 只算每个脉冲的概率，不管脉冲数。

端到端透过率

g.eta = p.etad .* 10 .^ (-p.alpha .* L ./ 10);

\[\eta=\eta_d\,10^{-\alpha L/10}.\]

推导：光纤每公里损耗 \(\alpha\) dB，走 \(L\) 公里共损耗 \(\alpha L\) dB； dB 转功率比为 \(10^{-\alpha L/10}\)；再乘探测器效率 \(\eta_d\)。

例：\(\alpha=0.2\)、\(L=100\) 时 \[\alpha L=20\ \text{dB},\qquad 10^{-20/10}=10^{-2}=0.01,\qquad \eta=0.5\times0.01=0.005.\] 意思：光走 100 km，再乘探测器效率，一千个光子里约 5 个能被探测到。

“至少收到一个光子”的概率

g.eta_u = 1 - exp(-g.eta .* p.u);
g.eta_v = 1 - exp(-g.eta .* p.v);

弱相干光源的光子数服从泊松分布，平均光子数为 \(\eta l\)。一个都没收到的概率为 \(e^{-\eta l}\)，所以至少收到一个： \[P(\ge 1)=1-e^{-\eta l}.\]

例（\(\eta=0.005\)）：

强度 计算 结果
\(u=0.5\) \(1-e^{-0.0025}\) \(2.496878\times10^{-3}\)
\(v=0.1\) \(1-e^{-0.0005}\) \(4.998750\times10^{-4}\)

注意： g.eta_u 不是“\(u\) 的透过率”，而是“光强 \(u\) 的脉冲至少被探测到一个光子的概率”。 真正的透过率是 g.eta。

增益 \(Q\)

g.Qu = p.Y0 + g.eta_u;
g.Qv = p.Y0 + g.eta_v;

\[Q_l=Y_0+\left(1-e^{-\eta l}\right).\]

两项相加的原因：没有真实光子时，探测器可能自己瞎响（\(Y_0\)）；有真实光子时，可能被探测到 （\(1-e^{-\eta l}\)）。所以总响应概率是两者之和，且物理上 \(Q_l\ge Y_0\)。

误码率 \(E\)

g.Eu = (p.e0 .* p.Y0 + p.ed .* g.eta_u) ./ g.Qu;
g.Ev = (p.e0 .* p.Y0 + p.ed .* g.eta_v) ./ g.Qv;

\[E_l=\frac{e_0Y_0+e_d\left(1-e^{-\eta l}\right)}{Q_l}.\]

分子是“错的概率”：

来源 概率 说明
暗计数猜错 \(e_0Y_0\) 没收到光子，只能瞎猜，错一半
真实光子判错 \(e_d(1-e^{-\eta l})\) 器件/对准不完美

分母是“响的概率”\(Q_l\)，所以 \(E_l\) 是条件概率：在响了的脉冲里，错的比例。

误码计数 \(T\)

g.Tu = g.Eu .* g.Qu;
g.Tv = g.Ev .* g.Qv;

\[T_l=E_lQ_l=P(\text{响应且出错}).\]

它和 \(E\) 的区别：\(E=P(\text{错}\mid\text{响应})\)，\(T=P(\text{响应且错})\)。 \(T\) 是联合概率，不是“个数”。真正的期望错误个数是 \(T N_l\)。

为什么 gain 不含 \(N\)

\(Q,E,T\) 都是每个脉冲的比例。脉冲数要到 estimate 里才出现： \[N_{uZ}=P_uP_{Z\mid u}N,\qquad n_{Wz}=N_{uZ}Q_u+N_{vZ}Q_v.\] 这样分层的好处：换光纤、换探测器只改 gain；换脉冲数只在 estimate 乘一下。

第 3 层：统计层 fluct.m

为什么需要这一层

真实系统只能发有限个脉冲（题目里 \(10^8\sim10^{10}\)）。用有限样本估出来的 \(Q^*,T^*\) 和真值有偏差。安全分析必须给出： \[\text{我有 }1-\varepsilon\text{ 的把握，真值落在 }[\text{下界},\text{上界}]\text{ 内}.\] \(\varepsilon=10^{-7}\) 表示“说错的概率千万分之一”。

返回的是函数，不是数

D = qkd.fluct(method, eps);

[lo, hi] = D.Q (Q,  Nl, nW);
[lo, hi] = D.T (T,  Nl, nW);
[lo, hi] = D.Y0(Y0, N0);

  • \(N_l\)：这个强度在这个基里发了多少脉冲；

  • \(n_W\)：这个基里所有强度一共收到多少事件（霍夫丁要用）；

  • \(N_0\)：真空态脉冲数。

\(N\) 不在 fluct 的输入里，而是在调用 D.Q 时传进去。所以同一个 \(D\) 可以服务多个 \(N\)，缓存只看 method 和 eps。

三种方法

方法 偏差公式 \(\varepsilon=10^{-7}\) 时的系数
高斯 \(\Delta=\gamma\sqrt{x/N}\)，\(\gamma=\sqrt{2}\,\mathrm{erfc}^{-1}(\varepsilon)\) \(\gamma\approx5.327\)
霍夫丁 \(\Delta=\sqrt{n_W\ln(1/\varepsilon)/2}\,/N\) \(k=\sqrt{0.5\ln(1/\varepsilon)}\approx2.839\)
切尔诺夫（下界） \(\Delta=\sqrt{2x\ln(16/\varepsilon^4)}\) \(\approx11.60\sqrt{x}\)
切尔诺夫（上界） \(\widehat{\Delta}=\sqrt{2x\ln(\varepsilon^{-1.5})}\) \(\approx6.95\sqrt{x}\)

表中高斯/霍夫丁的 \(x\) 是比例（\(Q\) 或 \(T\)），切尔诺夫两式的 \(x\) 是计数 \(x=N_lQ_l\)。

三种方法的共同形式： \[\mathrm{lo}=\max(\text{点估计}-\Delta,0),\qquad \mathrm{hi}=\text{点估计}+\Delta.\]

高斯界的 \(\gamma\) 怎么来

标准正态分布的双尾概率为 \[P(|Z|>\gamma)=\mathrm{erfc}\!\left(\frac{\gamma}{\sqrt{2}}\right).\] 要求它等于 \(\varepsilon\)： \[\mathrm{erfc}\!\left(\frac{\gamma}{\sqrt{2}}\right)=\varepsilon \;\Longrightarrow\; \frac{\gamma}{\sqrt{2}}=\mathrm{erfc}^{-1}(\varepsilon) \;\Longrightarrow\; \gamma=\sqrt{2}\,\mathrm{erfc}^{-1}(\varepsilon).\] \(\varepsilon=10^{-7}\) 时 \(\gamma\approx5.327\)：要留 5.33 个标准差，才敢以 \(1-10^{-7}\) 的把握说真值在区间内。

切尔诺夫界为什么上下不对称

对计数 \(x\)，下尾大致满足 \[P(X\le x-\Delta)\lesssim e^{-\Delta^2/(2x)}.\] 代码里： \[\Delta=\sqrt{2x\ln(16/\varepsilon^4)} \quad\Longleftrightarrow\quad e^{-\Delta^2/(2x)}=\frac{\varepsilon^4}{16},\] \[\widehat{\Delta}=\sqrt{2x\ln(\varepsilon^{-1.5})} \quad\Longleftrightarrow\quad e^{-\widehat{\Delta}^2/(2x)}=\varepsilon^{1.5}.\] \(\varepsilon=10^{-7}\) 时，\(\varepsilon^4/16\approx6.25\times10^{-29}\) 极小， 所以 \(\Delta\) 很宽；\(\varepsilon^{1.5}\approx3.16\times10^{-11}\) 相对大， 所以 \(\widehat{\Delta}\) 较紧。下界更宽是刻意的：估 \(Y_1\) 要用 \(Q_v\) 的下界， 宽一点更安全。

注意： fluct.m 里 hoeffBoundY0 的形状是 \(\Delta Y_0=k\sqrt{Y_0}/N_0\)，而 D.Q/D.T 的霍夫丁形式是 \(\Delta=k\sqrt{n_W}/N\)。若把真空态的期望响应数理解为 \(n_W=Y_0N_0\)， 类比会得到 \(k\sqrt{Y_0/N_0}\)。当前代码写的是 \(k\sqrt{Y_0}/N_0\)。 如果要逐字对照指导书 (3.35)，建议确认这一处的原始定义。这不影响 “样本越多、区间越窄”的定性理解。

第 4 层：估计层 estimate.m

为什么不能直接算 \(Y_1,e_1\)

只有单光子脉冲真正安全：多光子脉冲可能被 PNS 攻击。但 Bob 收到响应时， 不知道刚才那个脉冲里有几个光子；能测到的只有“某个强度的总响应率 \(Q\)”和 “总误码率 \(E\)”。

诱骗态方法写出两个方程： \[\begin{aligned} Q_u&=P_0^uY_0+P_1^uY_1+P_2^uY_2+\cdots,\\ Q_v&=P_0^vY_0+P_1^vY_1+P_2^vY_2+\cdots. \end{aligned}\] 利用 \(u>v\) 把 \(Y_2\) 消掉，得到 \(Y_1\) 的下界；同理用误码计数得到 \(e_1\) 的上界。

第一步：算脉冲数

wZ_u = p.Pza_u;       wX_u = 1 - p.Pza_u;
wZ_v = p.Pza_v;       wX_v = 1 - p.Pza_v;

NuZ = p.Pu * wZ_u * N;
NvZ = p.Pv * wZ_v * N;
NuX = p.Pu * wX_u * N;
NvX = p.Pv * wX_v * N;
N0  = p.P0 * N;

三层过滤： \[\text{总脉冲数 }N\;\times\;\text{选强度的概率}\;\times\;\text{选基的概率} =\text{这个格子的脉冲数}.\] 默认 \(N=10^9\) 时：

量 计算 结果
\(N_{uZ}\) \(0.6\times0.5\times10^9\) \(3.0\times10^8\)
\(N_{vZ}\) \(0.3\times0.5\times10^9\) \(1.5\times10^8\)
\(N_{uX}\) \(0.6\times0.5\times10^9\) \(3.0\times10^8\)
\(N_{vX}\) \(0.3\times0.5\times10^9\) \(1.5\times10^8\)
\(N_0\) \(0.1\times10^9\) \(1.0\times10^8\)

真空态不选基，所以只有一个 \(N_0\)。

第二步：真空态响应率的上下界

[Y0_lo, Y0_hi] = D.Y0(p.Y0, N0);

分母：

公式推导思路

写出两个强度的增益： \[\begin{aligned} Q_u&=P_0^uY_0+P_1^uY_1+P_2^uY_2+H_u,\\ Q_v&=P_0^vY_0+P_1^vY_1+P_2^vY_2+H_v, \end{aligned}\] 其中 \(H\) 是三光子及以上的贡献。为了消掉 \(Y_2\)，计算 \[P_2^vQ_u-P_2^uQ_v.\] 整理后 \(Y_2\) 项抵消： \[\begin{aligned} \left(P_1^vP_2^u-P_1^uP_2^v\right)Y_1 ={}&P_2^uQ_v-P_2^vQ_u +\left(P_2^vP_0^u-P_2^uP_0^v\right)Y_0 \\ &-\left(P_2^uH_v-P_2^vH_u\right). \end{aligned}\] 对 \(u>v\)、\(n\ge3\)，可以证明 \(P_2^uP_n^v-P_2^vP_n^u<0\)，所以 \(P_2^uH_v-P_2^vH_u\le0\)。把它丢掉，右边只会更小，于是得到下界。

公式 (3.29)：单光子误码率上界

误码计数： \[T_l=E_lQ_l =P_0^le_0Y_0+P_1^le_1Y_1+\sum_{n\ge2}P_n^le_nY_n.\] 丢掉非负的高阶项： \[T_v\ge P_0^ve_0Y_0+P_1^ve_1Y_1.\] 移项： \[e_1\le \frac{T_v-P_0^ve_0Y_0}{P_1^vY_1}.\]

任务 2：一维网格搜索（只优化信号态光强 \(u\)）

任务目标与调用链

任务 2 在 \(N=10^9\) 下比较高斯、霍夫丁、切尔诺夫三种统计界，并对每个距离点 单独选择最优信号态光强 \(u\)。它输出两张图：

  • fig2_three_methods：三种方法的 \(R\)–\(L\) 曲线；

  • fig2b_optimal_u：最优 \(u^*(L)\) 随距离的变化。

调用链：

run_task2
  -> qkd.runCase(p, spec)              % spec.opt = 'u'
       -> rateFor(p, L(i), spec, ug, p.v, p.Pu, p.Pv)
            -> qkd.keyRateAt(q, L(i), spec)
                 -> qkd.estimate(q, L(i), spec)

优化模型

对每个固定距离 \(L\)，只优化一个变量： \[u^*(L)=\operatorname*{arg\,max}_{u\in\mathcal{U}} R(L;u,v,P_u,P_v),\] 其中 \[\mathcal{U}=\{0.10+j\Delta u\}_{j=0}^{600},\qquad \Delta u=\frac{1.30-0.10}{600}=0.002.\] \(v,P_u,P_v\) 保持题目给定值不变，只有 \(u\) 在 \([0.10,1.30]\) 上搜索。

为什么用网格而不是梯度法：

  • 只有一维，601 个点完全可以穷举；

  • \(R(u)\) 经过诱骗态估计和统计界，解析导数很难写；

  • 网格搜索是确定性的，不引入随机性，容易复现和解释。

代码实现

任务脚本中的 spec：

spec = struct('method', meth{k}, 'N', 1e9, 'eps', 1e-7, ...
              'L', [0 300 1], 'opt', 'u', ...
              'optU', struct('lb', 0.10, 'ub', 1.30, ...
                             'n', 601, 'mode', 'perDistance'));

runCase 的 u 模式分支：

ug = linspace(spec.optU.lb, spec.optU.ub, spec.optU.n);

for i = 1:n
    Rv = rateFor(p, L(i), spec, ug, p.v, p.Pu, p.Pv);
    [rmax, k] = max(Rv);
    out.R(i) = rmax;
    out.u(i) = ug(k);
end

关键点：rateFor 的第四个参数是向量 ug，不是标量。 keyRateAt 以及它调用的 gain、estimate 全部使用逐元素运算， 所以一次调用就能算出 601 个候选的 \(R\)，返回长度 601 的向量 Rv。 然后 max 找出最大值与下标，把对应的 \(u\) 记进 out.u(i)。

这样距离循环只执行 301 次，而不是 \(301\times601\) 次； 601 个候选的评估被压在每次向量化调用里。

另一种模式：整段统一 \(u\)

runCase 还支持 mode 设为 fixed：整条曲线用一个 \(u\)。 实现是先把所有候选算成矩阵：

Rm = zeros(numel(ug), n);
for i = 1:n
    Rm(:, i) = rateFor(p, L(i), spec, ug, p.v, p.Pu, p.Pv);
end
[~, uIdx] = max(sum(Rm > 0, 2));
out.R = Rm(uIdx, :);
out.u = ug(uIdx) * ones(1, n);

对矩阵 Rm 的每一行，统计该候选能让多少个距离点保持正密钥 （即该行大于 0 的元素个数），取最大的那个，即“传得最远”的 \(u\)。 任务 2 用的是 perDistance，不是这个模式，但理解它有助于回答 “实际系统能不能按距离换 \(u\)”。

复杂度、精度与一个注释不一致

任务 2 的候选评估量： \[3\text{ 种方法}\times301\text{ 个距离}\times601\text{ 个候选} =543{,}903\text{ 次单点 }R\text{ 评估}.\] 由于每次 rateFor 一次算 601 个候选，实际只发生 \(3\times301=903\) 次向量化调用。

网格分辨率 \(\Delta u=0.002\)。argmax 给出的 \(u^*\) 与真实连续最优最多差半个网格； 由于 \(R(u)\) 在最优附近通常较平，密钥率的误差远小于 \(0.002\) 本身。

注意： 当前 run_task2.m 里写的是 n = 601，但同一行的注释仍写“61 个候选”。 以代码为准。工程文档里任务 2 的实测数字是按 n = 61 记录的； 如果重新用 601 跑，\(L_{\max}\) 和 \(u^*(L)\) 可能有轻微变化。

物理读图：\(u^*(L)\) 为什么随距离下降

近距离时，光纤损耗小，可以适当提高 \(u\) 来增加响应率； 远距离时，单光子到达率已经很低，如果 \(u\) 太大，多光子比例上升， 诱骗态估计给出的 \(Y_1^{Z,L}\) 下界会被压得更低，反而得不偿失。 所以最优 \(u\) 通常随距离单调下降——这也是 fig2b_optimal_u 想回答的问题。

工程文档中的一组实测值（n = 61 时）： 高斯 \(L_{\max}=176\) km，霍夫丁 \(157\) km，切尔诺夫 \(164\) km。 当前 run_task2.m 改为 n = 601 后，数值可能略有变化。

任务 3：四维全局优化（差分进化 + 坐标下降）

任务目标

任务 3 在切尔诺夫界、\(N=10^9\) 下，同时优化四个参数： \[(u,\ v,\ P_u,\ P_v).\] 先跑一条 opt 为 none 的基准曲线，再跑 opt 为 global 的优化曲线， 比较最远成码距离和同距离下的速率增益。

为什么不能继续网格搜索

任务 2 的一维网格只有 601 个点；如果四个维度各取 30 个点，组合数是 \[30^4=810{,}000,\] 而且每个候选都要跑完整的 gain、fluct、estimate、 keyRateAt 链。目标函数还非凸、带约束、没有解析梯度。所以任务 3 不再穷举，而是用差分进化（Differential Evolution, DE）做全局搜索， 再用坐标下降做局部打磨。

优化变量、边界与约束

代码把四个变量写成 \[x=(u,\ v/u,\ P_u,\ P_v),\] 第二维用比值 \(v/u\) 而不是 \(v\) 本身。这样做有两个好处：

  • 只要 \(v/u<1\)，就自动保证 \(v<u\)，不会出现 (3.28) 分母变号；

  • \(u\) 和 \(v\) 同比例缩放时比值不变，搜索空间更“正”。

边界：

变量 下界 上界
\(u\) 0.10 1.40
\(v/u\) 0.02 0.90
\(P_u\) 0.05 0.90
\(P_v\) 0.02 0.90

目标函数就是完整链算出的密钥率： \[f(x)=R(L;u,v,P_u,P_v),\] 但 objFun 会把不合法的候选直接判 0： \[\begin{aligned} v&\ge u &&\Rightarrow f=0,\\ P_u+P_v&>0.95 &&\Rightarrow f=0,\\ P_u&\le0\ \text{或}\ P_v\le0 &&\Rightarrow f=0. \end{aligned}\] \(P_u+P_v\le0.95\) 是为了给真空态至少留 \(5\%\) 的样本； 否则 \(Y_0\) 估不准，整个诱骗态估计会失效。计算中出现的 NaN/Inf 也一律记 0。

内层：差分进化

每一代种群有 npop 个个体，每个个体是一个四维候选。任务 3 用 npop=30、ngen=40；runCase 的默认值是 40 和 60。

伪代码：

pop = lb + rand(npop, Dm) .* (ub - lb);
fit = objFun(p, L, spec, pop);

for g = 1:ngen
    for i = 1:npop
        pick three random indices r1, r2, r3
        mutant(i,:) = pop(r1,:) + F*(pop(r2,:) - pop(r3,:));
        mutant(i,:) = clamp(mutant(i,:), lb, ub);
    end
    crossover ...
    trial = pop;  trial(cross) = mutant(cross);
    ft = objFun(p, L, spec, trial);
    where ft > fit:  pop = trial;  fit = ft;
end
xb = best individual;

三个核心公式。

变异（mutation）： \[m_i=x_{r_1}+F\,(x_{r_2}-x_{r_3}),\qquad F=0.6.\] 拿两个个体的差去推第三个个体；\(F\) 是步长。

交叉（crossover）： \[t_{i,d}= \begin{cases} m_{i,d}, & U_{i,d}\le CR\ \text{或}\ d=d_{\text{rand}},\\ x_{i,d}, & \text{otherwise}, \end{cases} \qquad CR=0.7.\] 每个维度以 \(70\%\) 的概率采用变异结果；\(d_{\text{rand}}\) 保证至少有一维来自变异， 否则试验个体可能和父代完全一样，进化白做。

选择（selection）： \[x_i\leftarrow \begin{cases} t_i, & f(t_i)>f(x_i),\\ x_i, & \text{otherwise}. \end{cases}\] 只留更好的，这就是“进化”。

objFun 支持矩阵输入：一次传入 npop\(\times4\) 的候选矩阵， 返回 npop\(\times1\) 的得分向量。因为 keyRateAt 是逐元素运算， 一整代可以在一次调用里评估完。

可复现性与两个实现细节

optimizeGlobal 开头有

rng(20260101);

固定随机种子，保证每次运行得到完全一样的结果。

  • 这个 rng 在每个粗距离点都会调用一次，所以每个点都从同一条随机序列开始。 好处是完全可复现；代价是各点的随机流不是独立的。若想要独立重复，可以把 rng 移到外层，或按距离设置不同种子。

  • 抽取参照个体用的是 randperm(npop,3)，它没有排除当前个体 \(i\)。 标准 DE 通常要求 \(r_1,r_2,r_3\) 与 \(i\) 不同；这里属于实现细节， 对启发式搜索影响有限，但严格实现可以从“其余个体”中抽样。

局部打磨：坐标下降

差分进化擅长“找到大致方向”，但不擅长“精确到小数点后三位”。所以在最优个体附近 再做一次无导数局部搜索：

for iter = 1:30

    end
end

数学上就是逐维坐标搜索： \[x^{(k+1)}=x^{(k)}+s_d\,\mathrm{step}_d\,\mathbf{e}_d, \qquad s_d\in\{-1,+1\},\] 有改进就接受；一整轮都没改进就把步长减半；四个维度的步长都小于 \(10^{-4}\) 时停止。

为什么用坐标下降而不是梯度法：目标函数经过约束裁剪、统计界和截断， 既不光滑也没有可靠导数；坐标搜索只需要比较函数值，稳健且实现简单。

回到 1 km：插值参数，不插值曲线

粗网格只有 61 个点，最终要输出 301 个 1 km 点。代码的做法是：

  1. 只保留“参数有限且 \(R>0\)”的粗点；

  2. 把这些粗点的最优参数插值到所有 1 km 点： \[x(L)=\mathrm{interp1}\!\left(L_{\text{coarse}},x^*_{\text{coarse}},L, \text{linear},\mathrm{NaN}\right);\]

  3. 用插值出来的参数，在每个 1 km 点重新算一次完整的 \(R\)。

为什么插值参数而不是直接插值 \(R\)：

  • \(R(L)\) 随距离指数下降，线性插值曲线会明显失真；

  • 最优参数 \(u^*(L),v^*(L),P_u^*(L),P_v^*(L)\) 变化平滑，适合插值；

  • 每个细点都用真实模型重算，结果是“真算出来的”，只是参数未必对该点最优， 所以略偏保守（宁可低估）。

范围外的插值返回 NaN，进入 keyRateAt 后被截成 \(R=0\)， 所以曲线不会出现 NaN。

断崖区细化

粗网格每 5 km 才一个点，可能把最后不到 5 km 的成码区漏掉，让 \(L_{\max}\) 少算几公里。 所以代码在“最后一个有密钥的粗点”和“下一个粗点”之间，逐点重新优化：

kl = find(Rc > 0, 1, 'last');
if ~isempty(kl) && kl < nc
    for i = idxC(kl)+1 : idxC(kl+1)-1
        [xb, fb] = optimizeGlobal(p, L(i), spec, gopt);
        out.u(i)  = xb(1);
        out.v(i)  = xb(1) * xb(2);
        out.Pu(i) = xb(3);
        out.Pv(i) = xb(4);
        out.R(i)  = fb;
    end
end

这一段最多只有 4 个点，但能把 \(L_{\max}\) 补准。

收尾：无密钥区的参数

dead = out.R <= 0;
out.u(dead) = NaN;  out.v(dead) = NaN;
out.Pu(dead) = NaN; out.Pv(dead) = NaN;

没有密钥的区域不存在“最优参数”，置成 NaN 后画图会自然断开，不会出现无意义的跳变。 \(L_{\max}\) 仍然定义为最后一个 \(R>0\) 的距离。

物理读图：四个最优参数为什么随距离漂移

  • 近距离：可以适当提高 \(u\)、降低 \(v\)，用更强的信号换响应率；

  • 远距离：单光子到达率低，必须提高 \(v\) 与 \(P_v\) 才能把单光子参数估准， 同时压低 \(u\)，避免多光子比例过高；

  • \(P_u\) 与真空态概率 \(P_0=1-P_u-P_v\) 互相挤压：\(P_u\) 太大，真空样本太少， \(Y_0\) 的统计误差变大，反而会拖累远端性能。

常见误解

① “\(N\) 不同，fluct 会重新算吗？”

不会。\(N\) 不是 fluct 的输入；fluct 只看 method 和 eps。 \(N\) 是在调用 D.Q(Q, Nl, nW) 时才传进去的。 \[N\text{ 不同}\;\Longrightarrow\;\text{缓存照样命中}\;\Longrightarrow\; \text{但 }D.Q\text{ 用新的 }N\text{ 重新算}\;\Longrightarrow\;\text{区间数值不同}.\]

② \(Q,E,T\) 是什么关系

\[\begin{aligned} Q&=P(\text{响应}),\\ E&=P(\text{错}\mid\text{响应}),\\ T&=P(\text{响应且错})=Q\,E. \end{aligned}\] \(Q\) 管“响不响”；\(E\) 管“响得对不对”；\(T\) 是两者的联合概率。

③ p.P0 和 \(P_0^u\) 不是一回事

  • p.P0：Alice 选择发送真空态的概率（默认 0.1）；

  • \(P_0^u=e^{-u}\)：信号态脉冲里零光子的比例（默认 0.6065）。

④ g.eta 和 g.eta_u 不是一回事

  • g.eta：一个光子的端到端透过率；

  • g.eta_u：一个多光子脉冲里“至少有一个光子被探测到”的概率。

⑤ \(T\) 是概率，不是个数

\(T\) 是每个脉冲“既响应又出错”的概率。期望个数要乘脉冲数：\(T N_l\)。

⑥ \(Y_1,e_1\) 不是实验量

实验只能测 \(Q,E\)。\(Y_1,e_1\) 是由诱骗态公式估出来的上下界，不是直接测量值。

⑦ \(v\) 不直接进最终密钥率公式

\(v,P_v,P_{Z\mid v}\) 只参与 estimate，用来估 \(Y_1,e_1\)。 最终 \(R\) 公式里看不到 \(v\)，因为诱骗态本身不生成密钥，它的作用是“当参照物”。

⑧ 优化不会污染原始参数

rateFor 里先 q = p 复制，再改 q。MATLAB 值语义保证调用方的 p 不变。
