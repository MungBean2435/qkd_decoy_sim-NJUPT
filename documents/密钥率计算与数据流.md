# 密钥率计算：需要什么、数据怎么得来、怎么流动

> 本文回答三个问题：
>
> 1. **算一条 `R(L)` 曲线，到底需要哪些量？**
> 2. **每个量是从哪一步、用什么公式得到的？**
> 3. **这些量按什么顺序流过程序？**
>
> 以任务 1（高斯统计界、不优化、`N = 1e8/1e9/1e10`）为主线；
> 任务 2、3 只在“优化参数”处做补充说明。
>
> 所有公式与代码一一对应，代码位置以当前仓库为准。
>
> LaTeX 排版版本：[密钥率计算与数据流.tex](密钥率计算与数据流.tex)，用 XeLaTeX 编译。

## 0. 结论先行

一条密钥率曲线的计算链只有四步：

```
题目参数 p
   │
   ├─① gain.m      把物理参数变成“可观测量”：Q、E、T
   │
   ├─② fluct.m     给可观测量配上“统计置信区间”
   │
   ├─③ estimate.m  用两个强度的可观测量，反推单光子参数的安全界：Y1Lz、e1Ux
   │
   └─④ keyRateAt.m 把“资格系数 ×（单光子收入 − 纠错支出）”拼成 R
```

`runCase.m` 只是把上面四步按距离逐点调用，并整理成数组：

```
R(L) = [ keyRateAt(p, L₁), keyRateAt(p, L₂), ..., keyRateAt(p, L₃₀₁) ]
```

**一句话：**

> 密钥率 = 资格系数 ×（单光子收入 − 纠错支出）。
> 收入里的单光子参数测不到，只能用“信号态 + 诱骗态 + 真空态”的可测量去估一个安全界。

## 1. 密钥率公式：最终需要哪些量

代码在 [`+qkd/keyRateAt.m`](../+qkd/keyRateAt.m) 第 58–59 行：

```matlab
R = p.Pu .* p.Pza_u .* p.Pzb .* ...
    (d.P1u .* Y1Lz .* (1 - H2(e1Ux)) - d.Qu .* p.f .* H2(d.Eu));
```

写成公式：

```
R = P_u · P_{Z|u}^A · P_Z^B
    × [ P_1^u · Y_1^{Z,L} · (1 − H2(e_1^{X,U}))
        − Q_u · f · H2(E_u) ]
```

逐项拆开：

| 项 | 代码 | 含义 | 从哪来 |
| --- | --- | --- | --- |
| `P_u` | `p.Pu` | 信号态选择概率 | `params.m` |
| `P_{Z∣u}^A` | `p.Pza_u` | 信号态下 Alice 选 Z 基的概率 | `params.m` |
| `P_Z^B` | `p.Pzb` | Bob 选 Z 基的概率 | `params.m` |
| `P_1^u` | `d.P1u` | 信号态脉冲恰好含 1 个光子的概率 | 由 `p.u` 算泊松 |
| `Y_1^{Z,L}` | `Y1Lz` | Z 基单光子响应率的**下界** | `estimate.m` |
| `e_1^{X,U}` | `e1Ux` | X 基单光子误码率的**上界** | `estimate.m` |
| `Q_u` | `d.Qu` | 信号态增益 | `gain.m` |
| `f` | `p.f` | 纠错效率 | `params.m` |
| `E_u` | `d.Eu` | 信号态误码率 | `gain.m` |
| `H2(·)` | 匿名函数 | 二进制熵 | `keyRateAt.m` 内定义 |

**关键观察：**

- 公式里只有 `Q_u` 和 `E_u` 是“信道直接给的”；
- `Y_1` 和 `e_1` **永远测不到**，必须由 `estimate.m` 用诱骗态数据反推上下界；
- 估计 `Y_1`/`e_1` 又需要 `Q_v`、`T_v`、`Y_0`——所以 `gain.m` 才要算一整套，而不是只算 `Q_u`、`E_u`。

## 2. 总体数据流：五层

```
┌─────────────────────────────────────────────────────────────┐
│ 第 1 层  参数层  +qkd/params.m                              │
│   α, η_d, d, e_d, e_0, u, v, P_u, P_v, P_{Z|u}, P_Z, f     │
│   派生：Y_0 = 2d(1−d)，P_0 = 1−P_u−P_v                      │
└───────────────────────────┬─────────────────────────────────┘
                            │ p
                            ▼
┌─────────────────────────────────────────────────────────────┐
│ 第 2 层  物理层  +qkd/gain.m                                │
│   η → η_u/η_v → Q_u/Q_v → E_u/E_v → T_u/T_v                 │
│   输出全是“每个脉冲的概率”                                   │
└───────────────────────────┬─────────────────────────────────┘
                            │ g
                            ▼
┌─────────────────────────────────────────────────────────────┐
│ 第 3 层  统计层  +qkd/fluct.m                               │
│   按 method/eps 返回三个界限函数 D.Q / D.T / D.Y0           │
│   把“点估计 ± 偏差”变成“置信区间”                           │
└───────────────────────────┬─────────────────────────────────┘
                            │ D
                            ▼
┌─────────────────────────────────────────────────────────────┐
│ 第 4 层  估计层  +qkd/estimate.m                            │
│   脉冲数 → Q/T/Y0 的上下界 → 泊松项 → (3.28)(3.29)          │
│   输出：Y1Lz（下界）、e1Ux（上界）                           │
└───────────────────────────┬─────────────────────────────────┘
                            │ Y1Lz, e1Ux, d
                            ▼
┌─────────────────────────────────────────────────────────────┐
│ 第 5 层  密钥率层  +qkd/keyRateAt.m                         │
│   H2 → 收入/支出 → R；负数/NaN 截成 0                       │
└───────────────────────────┬─────────────────────────────────┘
                            │ R
                            ▼
┌─────────────────────────────────────────────────────────────┐
│ 调度层  +qkd/runCase.m                                      │
│   逐距离调用 → R(L) → Lmax → 返回给 tasks/ 画图              │
└─────────────────────────────────────────────────────────────┘
```

各层职责：

| 层 | 文件 | 输入 | 输出 | 是否含物理公式 |
| --- | --- | --- | --- | --- |
| 参数 | `params.m` | 无 | `p` | 只有参数定义与派生量 |
| 物理 | `gain.m` | `p, L` | `g`（Q、E、T） | 是 |
| 统计 | `fluct.m` | `method, eps` | `D`（三个句柄） | 统计界公式 |
| 估计 | `estimate.m` | `p, L, spec` | `Y1Lz, e1Ux, d` | 是 |
| 密钥率 | `keyRateAt.m` | `p, L, spec` | `R, d` | 是 |
| 调度 | `runCase.m` | `p, spec` | `out`（`L, R, Lmax`…） | 否 |
| 出图 | `tasks/run_task*.m` | 无 | PNG/CSV | 否 |

## 3. 第 1 层：参数层 `params.m`

### 3.1 题目给定的参数

| 代码字段 | 符号 | 含义 | 默认值 | 单位 |
| --- | --- | --- | ---: | --- |
| `p.u` | u | 信号态平均光子数 | 0.5 | 个/脉冲 |
| `p.v` | v | 诱骗态平均光子数 | 0.1 | 个/脉冲 |
| `p.Pu` | P_u | 信号态选择概率 | 0.6 | — |
| `p.Pv` | P_v | 诱骗态选择概率 | 0.3 | — |
| `p.Pza_u` | P_{Z∣u}^A | 信号态下 Alice 选 Z 基 | 0.5 | — |
| `p.Pza_v` | P_{Z∣v}^A | 诱骗态下 Alice 选 Z 基 | 0.5 | — |
| `p.Pzb` | P_Z^B | Bob 选 Z 基 | 0.5 | — |
| `p.f` | f | 纠错效率 | 1.16 | — |
| `p.alpha` | α | 光纤损耗 | 0.2 | dB/km |
| `p.etad` | η_d | 探测器效率 | 0.5 | — |
| `p.d` | d | 单探测器暗计数 | 1e-6 | 每脉冲 |
| `p.ed` | e_d | 本底误码率 | 0.015 | — |
| `p.e0` | e_0 | 真空态误码率（瞎猜） | 0.5 | — |

### 3.2 两个派生量

**真空态响应率：**

```
Y_0 = 2d(1 − d)
```

Bob 有两个探测器，任一“瞎响”都算响应：

```
1 − (1−d)² = 2d − d² = 2d(1−d)
```

默认值 `d = 1e-6` 时，`Y_0 ≈ 2e-6`。

**真空态选择概率：**

```
P_0 = 1 − P_u − P_v
```

默认 `1 − 0.6 − 0.3 = 0.1`。

> ⚠️ 两个“真空”不要混：
>
> - `p.P0 = 0.1`：Alice **选择发送真空态脉冲**的概率；
> - `P_0^u = e^{-u}`：**信号态脉冲里恰好含 0 个光子**的概率。
>
> 前者决定“真空样本有多少个”，后者出现在诱骗态公式里。

### 3.3 参数在哪一层被用到

| 参数 | `gain` | `estimate` | `keyRateAt` |
| --- | :---: | :---: | :---: |
| `u, v` | ✅ | ✅ | `u`（算 P1u） |
| `Pu, Pv, P0` | — | ✅（算脉冲数） | `Pu` |
| `Pza_u, Pza_v` | — | ✅ | `Pza_u` |
| `Pzb` | — | — | ✅ |
| `alpha, etad` | ✅ | — | — |
| `d → Y0` | ✅ | ✅ | — |
| `ed, e0` | ✅（E） | `e0`（e1 公式） | — |
| `f` | — | — | ✅ |

## 4. 第 2 层：物理层 `gain.m`

`gain` 只算**每个脉冲的概率**，不管脉冲数。代码在 [`+qkd/gain.m`](../+qkd/gain.m)。

### 4.1 端到端透过率

```matlab
g.eta = p.etad .* 10 .^ (-p.alpha .* L ./ 10);
```

```
η = η_d · 10^(−αL/10)
```

**推导：**

- 光纤每公里损耗 `α` dB，走 `L` 公里共损耗 `αL` dB；
- dB 转功率比：`10^(−dB/10)`；
- 再乘探测器效率 `η_d`。

例：`α = 0.2`、`L = 100` 时

```
αL = 20 dB
10^(−20/10) = 10^(−2) = 0.01
η = 0.5 × 0.01 = 0.005
```

意思：光走 100 km，再乘探测器效率，一千个光子里约 5 个能被探测到。

### 4.2 “至少收到一个光子”的概率

```matlab
g.eta_u = 1 - exp(-g.eta .* p.u);
g.eta_v = 1 - exp(-g.eta .* p.v);
```

弱相干光源的光子数服从泊松分布，平均光子数为 `η·l`。一个都没收到的概率：

```
P(0) = e^(−ηl)
```

所以至少收到一个：

```
P(≥1) = 1 − e^(−ηl)
```

例（`η = 0.005`）：

| 强度 | 计算 | 结果 |
| --- | --- | ---: |
| `u = 0.5` | `1 − e^(−0.0025)` | `2.496878e-3` |
| `v = 0.1` | `1 − e^(−0.0005)` | `4.998750e-4` |

> 命名提醒：`g.eta_u` 不是“u 的透过率”，而是“光强 u 的脉冲至少被探测到一个光子的概率”。

### 4.3 增益 Q

```matlab
g.Qu = p.Y0 + g.eta_u;
g.Qv = p.Y0 + g.eta_v;
```

```
Q_l = Y_0 + (1 − e^(−ηl))
```

两项相加的原因：

- 没有真实光子时，探测器可能自己瞎响（`Y_0`）；
- 有真实光子时，可能被探测到（`1 − e^(−ηl)`）。

所以总响应概率是两者之和，且物理上 `Q_l ≥ Y_0`。

### 4.4 误码率 E

```matlab
g.Eu = (p.e0 .* p.Y0 + p.ed .* g.eta_u) ./ g.Qu;
g.Ev = (p.e0 .* p.Y0 + p.ed .* g.eta_v) ./ g.Qv;
```

```
E_l = (e_0·Y_0 + e_d·(1 − e^(−ηl))) / Q_l
```

分子是“错的概率”：

| 来源 | 概率 | 说明 |
| --- | --- | --- |
| 暗计数猜错 | `e_0·Y_0` | 没收到光子，只能瞎猜，错一半 |
| 真实光子判错 | `e_d·(1 − e^(−ηl))` | 器件/对准不完美 |

分母是“响的概率” `Q_l`，所以 `E_l` 是**条件概率**：在响了的脉冲里，错的比例。

### 4.5 误码计数 T

```matlab
g.Tu = g.Eu .* g.Qu;
g.Tv = g.Ev .* g.Qv;
```

```
T_l = E_l · Q_l = P(响应且出错)
```

它和 `E` 的区别：

- `E = P(错 | 响应)`；
- `T = P(响应 且 错)`。

`T` 是联合概率，不是“个数”。真正的期望错误个数是 `T·N_l`。

### 4.6 为什么 `gain` 不含 N

`Q`、`E`、`T` 都是**每个脉冲的比例**。脉冲数要到 `estimate` 里才出现：

```
NuZ = P_u · P_{Z|u} · N
nWz = NuZ·Q_u + NvZ·Q_v
```

这样分层的好处：

- 换光纤、换探测器 → 只改 `gain`；
- 换脉冲数 → 只在 `estimate` 乘一下，`gain` 一行都不用动。

### 4.7 100 km 数值例子

参数：`α=0.2, η_d=0.5, u=0.5, v=0.1, d=1e-6, e_d=0.015, e_0=0.5`。

| 量 | 公式 | 数值 |
| --- | --- | ---: |
| `η` | `0.5 × 10^(−0.2×100/10)` | `5.000000e-3` |
| `η_u` | `1 − e^(−0.005×0.5)` | `2.496878e-3` |
| `η_v` | `1 − e^(−0.005×0.1)` | `4.998750e-4` |
| `Q_u` | `Y_0 + η_u` | `2.498878e-3` |
| `Q_v` | `Y_0 + η_v` | `5.018750e-4` |
| `E_u` | 上式 | `1.538824e-2` |
| `E_v` | 上式 | `1.693284e-2` |
| `T_u` | `E_u·Q_u` | `3.845316e-5` |
| `T_v` | `E_v·Q_v` | `8.498124e-6` |

## 5. 第 3 层：统计层 `fluct.m`

### 5.1 为什么需要这一层

真实系统只能发**有限个**脉冲（题目里 `1e8 ~ 1e10`）。用有限样本估出来的 `Q*`、`T*` 和真值有偏差。安全分析必须给出：

```
我有 1 − ε 的把握，真值落在 [下界, 上界] 内
```

`ε = 1e-7` 表示“说错的概率千万分之一”。

### 5.2 返回的是函数，不是数

```matlab
D = qkd.fluct(method, eps);

[lo, hi] = D.Q (Q,  Nl, nW);   % 增益的区间
[lo, hi] = D.T (T,  Nl, nW);   % 误码计数的区间
[lo, hi] = D.Y0(Y0, N0);       % 真空态响应率的区间
```

- `Nl`：这个强度在这个基里发了多少脉冲；
- `nW`：这个基里所有强度一共收到多少事件（霍夫丁要用）；
- `N0`：真空态脉冲数。

**`N` 不在 `fluct` 的输入里**，而是在调用 `D.Q` 时传进去。所以同一个 `D` 可以服务多个 `N`，缓存只看 `method` 和 `eps`。

### 5.3 三种方法

| 方法 | 偏差公式 | `ε=1e-7` 时的系数 |
| --- | --- | --- |
| 高斯 | `Δ = γ·√(x/N)`，`γ = √2·erfcinv(ε)` | `γ ≈ 5.327` |
| 霍夫丁 | `Δ = √(nW·ln(1/ε)/2) / N` | `k = √(0.5·ln(1/ε)) ≈ 2.839` |
| 切尔诺夫（下界） | `Δ = √(2x·ln(16/ε⁴))` | `≈ 11.60·√x`（计数空间） |
| 切尔诺夫（上界） | `Δ̂ = √(2x·ln(ε^(−1.5)))` | `≈ 6.95·√x`（计数空间） |

三种方法的共同形式：

```
lo = max(点估计 − 偏差, 0)
hi = 点估计 + 偏差
```

### 5.4 高斯界的 γ 怎么来

标准正态分布的双尾概率：

```
P(|Z| > γ) = erfc(γ/√2)
```

要求它等于 `ε`：

```
erfc(γ/√2) = ε
γ/√2 = erfc⁻¹(ε)
γ = √2 · erfc⁻¹(ε)
```

`ε = 1e-7` 时 `γ ≈ 5.327`：要留 5.33 个标准差，才敢以 1−1e-7 的把握说真值在区间内。

### 5.5 切尔诺夫界为什么上下不对称

对计数 `x`，下尾大致满足：

```
P(X ≤ x − Δ) ≲ exp(−Δ²/(2x))
```

代码里：

```
下界 Δ  = √(2x·ln(16/ε⁴))   → 对应尾概率 ε⁴/16
上界 Δ̂ = √(2x·ln(ε^(−1.5))) → 对应尾概率 ε^(1.5)
```

`ε = 1e-7` 时：

- `ε⁴/16 ≈ 6.25e-29`，极小 → `Δ` 很宽；
- `ε^1.5 ≈ 3.16e-11`，相对大 → `Δ̂` 较紧。

**下界更宽是刻意的**：估 `Y_1` 要用 `Q_v` 的下界，宽一点更安全。

### 5.6 读代码提示

`fluct.m` 里 `hoeffBoundY0` 的形状是：

```
ΔY_0 = k·√(Y_0) / N_0
```

而 `D.Q` / `D.T` 的霍夫丁形式是：

```
Δ = k·√(nW) / N
```

若把真空态的期望响应数理解为 `nW = Y_0·N_0`，类比会得到 `k·√(Y_0/N_0)`。
当前代码写的是 `k·√(Y_0)/N_0`。如果你要逐字对照指导书 (3.35)，建议确认这一处的原始定义。
这不影响“样本越多、区间越窄”的定性理解。

## 6. 第 4 层：估计层 `estimate.m`

代码在 [`+qkd/estimate.m`](../+qkd/estimate.m)。这是整个工程最核心的一段。

### 6.1 为什么不能直接算 Y1、e1

- 只有**单光子脉冲**真正安全：多光子脉冲可能被 PNS 攻击；
- 但 Bob 收到响应时，**不知道**刚才那个脉冲里有几个光子；
- 能测到的只有“某个强度的总响应率 `Q`”和“总误码率 `E`”。

诱骗态方法：

```
Q_u = P_0^u·Y_0 + P_1^u·Y_1 + P_2^u·Y_2 + ...
Q_v = P_0^v·Y_0 + P_1^v·Y_1 + P_2^v·Y_2 + ...
```

两个方程、多个未知数。利用 `u > v`，把 `Y_2` 消掉，得到 `Y_1` 的**下界**；
同理用误码计数得到 `e_1` 的**上界**。

### 6.2 第一步：算脉冲数

```matlab
wZ_u = p.Pza_u;       wX_u = 1 - p.Pza_u;
wZ_v = p.Pza_v;       wX_v = 1 - p.Pza_v;

NuZ = p.Pu * wZ_u * N;
NvZ = p.Pv * wZ_v * N;
NuX = p.Pu * wX_u * N;
NvX = p.Pv * wX_v * N;
N0  = p.P0 * N;
```

三层过滤：

```
总脉冲数 N × 选强度的概率 × 选基的概率 = 这个格子的脉冲数
```

默认 `N = 1e9` 时：

| 量 | 计算 | 结果 |
| --- | --- | ---: |
| `NuZ` | `0.6×0.5×1e9` | `3.0e8` |
| `NvZ` | `0.3×0.5×1e9` | `1.5e8` |
| `NuX` | `0.6×0.5×1e9` | `3.0e8` |
| `NvX` | `0.3×0.5×1e9` | `1.5e8` |
| `N0` | `0.1×1e9` | `1.0e8` |

真空态不选基，所以只有一个 `N0`。

### 6.3 第二步：真空态响应率的上下界

```matlab
[Y0_lo, Y0_hi] = D.Y0(p.Y0, N0);
```

真空态脉冲里没有光子，Bob 却响应，那只能是暗计数。它是最干净的噪声测量，所以用它校准后面所有估计。

### 6.4 第三步：Z 基增益的上下界

```matlab
nWz = NuZ .* g.Qu + NvZ .* g.Qv;
[QuZ_lo, QuZ_hi] = D.Q(g.Qu, NuZ, nWz);
[QvZ_lo, QvZ_hi] = D.Q(g.Qv, NvZ, nWz);
```

`nWz` 是 Z 基里两种强度一共收到的期望事件数。

### 6.5 第四步：X 基同样处理

```matlab
nWx = NuX .* g.Qu + NvX .* g.Qv;
[QuX_lo, QuX_hi] = D.Q(g.Qu, NuX, nWx);
[QvX_lo, QvX_hi] = D.Q(g.Qv, NvX, nWx);
[~, TvX_hi]      = D.T(g.Tv, NvX, nWx);
```

X 基用来估误码。`T_v` 只需要上界，所以用 `~` 丢掉下界。

### 6.6 第五步：泊松项

```matlab
np = @(n, l) exp(-l) .* l.^n ./ factorial(n);

P1u = np(1, p.u);  P2u = np(2, p.u);  P0u = np(0, p.u);
P1v = np(1, p.v);  P2v = np(2, p.v);  P0v = np(0, p.v);
```

泊松分布：

```
P_n^l = e^(−l) · l^n / n!
```

`u=0.5`、`v=0.1` 时：

| 项 | u=0.5 | v=0.1 |
| --- | ---: | ---: |
| `P_0` | `6.065307e-1` | `9.048374e-1` |
| `P_1` | `3.032653e-1` | `9.048374e-2` |
| `P_2` | `7.581633e-2` | `4.524187e-3` |

### 6.7 公式 (3.28)：单光子响应率下界

分母：

```matlab
den = P1v .* P2u - P1u .* P2v;
```

化简：

```
P1^v·P2^u − P1^u·P2^v
= e^(−(u+v)) · u·v·(u−v)/2
```

**只要 u > v，分母恒正**。这就是“诱骗态必须比信号态弱”的数学原因。

公式：

```
Y_1^{Z,L} =
  [ P_2^u·Q_v^L − P_2^v·Q_u^U + (P_2^v·P_0^u − P_2^u·P_0^v)·Y_0^U ]
  / (P_1^v·P_2^u − P_1^u·P_2^v)
```

代码：

```matlab
Y1Lz = (P2u .* QvZ_lo - P2v .* QuZ_hi + ...
        (P2v .* P0u - P2u .* P0v) .* Y0_hi) ./ den;
Y1Lz = max(Y1Lz, 0);
```

**为什么这样取上下界：**

| 量 | 取哪一侧 | 效果 |
| --- | --- | --- |
| `Q_v` | 下界 `QvZ_lo` | 分子变小 → `Y_1` 变小 |
| `Q_u` | 上界 `QuZ_hi` | 被减项变大 → `Y_1` 变小 |
| `Y_0` | 上界 `Y0_hi` | 系数在 `u>v` 时为负 → `Y_1` 变小 |

每一步都朝“让 `Y_1` 更小”的方向取——**宁少勿多**。

### 6.8 公式推导思路（3.28）

写出两个强度的增益：

```
Q_u = P_0^u·Y_0 + P_1^u·Y_1 + P_2^u·Y_2 + H_u
Q_v = P_0^v·Y_0 + P_1^v·Y_1 + P_2^v·Y_2 + H_v
```

其中 `H` 是 3 光子及以上的贡献。为了消掉 `Y_2`：

```
P_2^v·Q_u − P_2^u·Q_v
```

整理后 `Y_2` 项抵消，得到：

```
(P_1^v·P_2^u − P_1^u·P_2^v)·Y_1
= P_2^u·Q_v − P_2^v·Q_u
  + (P_2^v·P_0^u − P_2^u·P_0^v)·Y_0
  − (P_2^u·H_v − P_2^v·H_u)
```

对 `u > v`、`n ≥ 3`，可以证明 `P_2^u·P_n^v − P_2^v·P_n^u < 0`，所以
`P_2^u·H_v − P_2^v·H_u ≤ 0`。把它丢掉，右边只会更小，于是得到**下界**。

### 6.9 公式 (3.29)：单光子误码率上界

误码计数：

```
T_l = E_l·Q_l = P_0^l·e_0·Y_0 + P_1^l·e_1·Y_1 + Σ_{n≥2} P_n^l·e_n·Y_n
```

丢掉非负的高阶项：

```
T_v ≥ P_0^v·e_0·Y_0 + P_1^v·e_1·Y_1
```

移项：

```
e_1 ≤ (T_v − P_0^v·e_0·Y_0) / (P_1^v·Y_1)
```

代码：

```matlab
e1Ux = (TvX_hi - P0v .* p.e0 .* Y0_lo) ./ ...
       (P1v .* max(Y1Lx, realmin));
e1Ux = min(max(e1Ux, 0), 0.5);
```

**保守方向：**

| 量 | 取哪一侧 | 效果 |
| --- | --- | --- |
| `T_v` | 上界 `TvX_hi` | 分子变大 → `e_1` 变大 |
| `Y_0` | 下界 `Y0_lo` | 扣得少 → 分子更大 → `e_1` 变大 |
| `Y_1` | 下界 `Y1Lx` | 分母变小 → `e_1` 变大 |

`max(Y1Lx, realmin)` 防止除以 0；`min(max(..., 0), 0.5)` 把误码率限制在 `[0, 0.5]`。

### 6.10 估不出来时直接认输

```matlab
e1Ux(Y1Lx <= 0) = 0.5;
```

如果连单光子响应率都估不出来，就按最坏情况处理：单光子误码等同于瞎猜。
此时 `H2(0.5) = 1`，隐私放大扣掉全部比特，密钥率被压到 0。

`N = 1e9`、`ε = 1e-7`、高斯界：

| --- | ---: |

## 7. 第 5 层：密钥率层 `keyRateAt.m`

代码在 [`+qkd/keyRateAt.m`](../+qkd/keyRateAt.m)。

### 7.1 信号态单光子概率

```matlab
d.P1u = exp(-p.u) .* p.u;
```

```
P_1^u = e^(−u)·u
```

`u=0.5` 时 `P_1^u = 3.032653e-1`。

### 7.2 二进制熵

```matlab
H2 = @(x) -(x .* log2(max(x, realmin)) + ...
            (1 - x) .* log2(max(1 - x, realmin)));
```

```
H2(x) = −x·log₂(x) − (1−x)·log₂(1−x)
```

| x | H2(x) | 直觉 |
| --- | ---: | --- |
| 0 | 0 | 完全确定 |
| 0.5 | 1 | 最难猜 |
| 0.015 | ≈ 0.115 | 少量开销 |

`max(·, realmin)` 防止 `log2(0) = −Inf` 污染结果。

### 7.3 收入与支出

```
收入 = P_1^u · Y_1^{Z,L} · (1 − H2(e_1^{X,U}))
支出 = Q_u · f · H2(E_u)
```

- **收入**：单光子脉冲里，扣掉 Eve 可能知道的信息后，还能留下的比特；
- **支出**：纠错必须公开的比特数。

资格系数：

```
P_u · P_{Z|u}^A · P_Z^B = 0.6 × 0.5 × 0.5 = 0.15
```

只有“信号态 + Alice 选 Z + Bob 选 Z”的脉冲才参与成码。

### 7.4 截断

```matlab
R(~isfinite(R)) = 0;
R(R < 0) = 0;
```

- NaN/Inf：估计失效或参数越界，按“无密钥”处理；
- 负数：收入不够付支出，物理上意味着通信应停止。

截成 0 而不是删除，是为了让 `R` 和 `L` 保持一一对应。

## 9. 完整链路：从 `p` 到 `R`

### 9.1 公式链

```
p.alpha, p.etad, L
    ↓
η = η_d·10^(−αL/10)
    ↓
η_u = 1−e^(−ηu),  η_v = 1−e^(−ηv)
    ↓
Q_u = Y_0+η_u,  Q_v = Y_0+η_v
    ↓
E_u, E_v  →  T_u = E_uQ_u,  T_v = E_vQ_v
    ↓
D.Q / D.T / D.Y0 给出上下界
    ↓
P_1^u, P_2^u, P_0^u, P_1^v, P_2^v, P_0^v
    ↓
Y_1^{Z,L} = [P_2^uQ_v^L − P_2^vQ_u^U + (P_2^vP_0^u − P_2^uP_0^v)Y_0^U] / den
e_1^{X,U} = (T_v^U − P_0^v e_0 Y_0^L) / (P_1^v Y_1^{X,L})
    ↓
R = P_uP_{Z|u}^AP_Z^B · [P_1^uY_1^{Z,L}(1−H2(e_1^{X,U})) − Q_u f H2(E_u)]
```

### 9.2 函数调用栈

以任务 1 的单个距离点为例：

```
run_task1
 └─ qkd.runCase(p, spec)
     └─ rateFor(p, L(i), spec, ...)
         └─ qkd.keyRateAt(q, L(i), spec)
             ├─ qkd.estimate(q, L(i), spec)
             │   ├─ qkd.fluct(spec.method, spec.eps)
             │   │   └─ 返回 D.Q / D.T / D.Y0
             │   ├─ qkd.gain(q, L(i))
             │   │   └─ 返回 Q、E、T
             │   ├─ D.Y0(...) / D.Q(...) / D.T(...)
             │   └─ 套 (3.28)(3.29)
             ├─ 算 P1u
             ├─ 定义 H2
             └─ 套 (3.30)，截断负数/NaN
```

### 9.3 数据形状

| 阶段 | 标量情形 | 向量情形 |
| --- | --- | --- |
| `L` | 单个距离 | 1×301 |
| `p.u` | 0.5 | 优化时可能 1×61 或 1×301 |
| `Q、E、T` | 标量 | 与 `L`/参数同形状 |
| 上下界 | 标量 | 同形状 |

所有内核函数都用 `.*`、`./`、`.^` 写成逐元素运算，所以同一套代码能同时处理标量和数组。

## 11. 常见误解

### ① “`N` 不同，`fluct` 会重新算吗？”

不会。

`N` 不是 `fluct` 的输入；`fluct` 只看 `method` 和 `eps`。`N` 是在调用 `D.Q(Q, Nl, nW)` 时才传进去的。

```
N 不同 → 缓存照样命中 → 但 D.Q 用新的 N 重新算 → 区间数值不同
```

### ② `Q`、`E`、`T` 是什么关系

```
Q = P(响应)
E = P(错 | 响应)
T = P(响应 且 错) = Q·E
```

- `Q` 管“响不响”；
- `E` 管“响得对不对”；
- `T` 是两者的联合概率。

### ③ `p.P0` 和 `P0u` 不是一回事

- `p.P0`：Alice **选择发送真空态**的概率（默认 0.1）；
- `P0u = e^{-u}`：**信号态脉冲里零光子**的比例（默认 0.6065）。

### ④ `g.eta` 和 `g.eta_u` 不是一回事

- `g.eta`：一个光子的端到端透过率；
- `g.eta_u`：一个多光子脉冲里“至少有一个光子被探测到”的概率。

### ⑤ `T` 是概率，不是个数

`T` 是每个脉冲“既响应又出错”的概率。期望个数要乘脉冲数：

```
错误个数 = T · N_l
```

### ⑥ `Y1`、`e1` 不是实验量

实验只能测 `Q`、`E`。`Y1`、`e1` 是由诱骗态公式**估出来的上下界**，不是直接测量值。

### ⑦ `v` 不直接进最终密钥率公式

`v`、`Pv`、`Pza_v` 只参与 `estimate`，用来估 `Y1`、`e1`。
最终 `R` 公式里看不到 `v`，因为诱骗态本身不生成密钥，它的作用是“当参照物”。

### ⑧ 优化不会污染原始参数

`rateFor` 里先 `q = p` 复制，再改 `q`。MATLAB 值语义保证调用方的 `p` 不变。
